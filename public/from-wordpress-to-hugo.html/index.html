从 WordPress 到 Hugo

04 Aug, 2026

前几天服务器出现问题，导致原先部署在上面的 WordPress 博客加载和反应都很慢，Ping 值正常，但是负载一直很高，我找不到原因，疲于维护，索性直接放弃，在本地安装 Hugo 调试之后，直接部署到了 Cloudflare Pages 上。

还是韩宇说的对，小白更应该使用静态博客，只需要操心如何部署的问题，虽然我觉得这是很难的一步，但现在有了 AI，不懂的直接问，或者截图给它，都能一步一步教你解决。

四年前短暂用过一段时间 Hugo，对于一些基础操作还是记得很清楚，尽管仍然对 Git 等命令一窍不通，但现在我直接用 GitHub Desktop，省去了输命令的麻烦，遇到问题也直接找 ChatGPT，整个过程还是比较舒服和流畅的。

现在写博客就图一个顺心、安心、简单，其他的不考虑，使用仿 Bearblog 的主题，简简单单地写写字而已，至于评论，暂时也不打算加上，如果有想法和我交流，可以在关于页面找到我的联系方式。
