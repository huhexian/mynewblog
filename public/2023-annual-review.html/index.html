2023·年度回顾

16 Dec, 2023

陈仓颉在群里分享了一篇来自 Ness Labs 的文章，其中提到对2023年的年度回顾，根据作者提供的模板，从不同方面回顾过去一年，然后再记录最骄傲的成就、最大的挑战、明年最主要的愿望。我们与 Telegram 频道 @FindBlog 发起这项主题活动，欢迎大家一起参与。

尽管还没到2023年的最后一天，但剩下的日子也改变不了什么。原以为从2018年开始写博客起，每年都会写一篇总结或者回顾，刚刚翻博客才发现漏写了2019年，或许因为2019年是过去十年里最差的一年，也是未来十年里最好的一年。

2023年的方方面面

根据模板，主要从以下几个方面回顾过去一年。健康/锻炼、工作/职业、友情/社交、个人生活/家庭、学习/知识管理、旅游/文化、兴趣/创造、情绪/精神状况、财务状况。

健康/锻炼

健康状况还算良好，暑假实习前在医院做了一次简单的体检，没有什么毛病。上半年睡眠有很大的问题，一方面在于环境比较差，容易被室友半夜的呼噜声吵醒，另一方面自己睡得比较晚，入睡慢，但下半年有所改善，通过调整自己的作息时间、戴耳塞等方式，让自己尽快入睡，以及提高深睡度。

年年说要运动，但年年都是“永远在路上”。通过华为手环和华为运动健康软件，也记录了我在2023年的一点点运动。

3月份跑了1公里，9月份跑了两次，加起来5公里，总共6公里。算了，我都不好意思细说。

再加上今年课不多，尤其是下半年，出门的次数更少，原本给自己定的年度目标中计划行走500万步，到现在也只达成55%，比去年更低。其实我挺喜欢跑步，特别是在压力大的情况下，跑几圈出个汗，内心会非常舒畅。

到此为止，越说越丢脸。

工作/职业

我从2022年10月到现在一直在做一份兼职，给公众号写稿子，虽然没有多少技术含量，但每个月的稿费足够支付我在学校的生活费，今年3月份稿费也有所提高。每个月写25篇，坚持了1年多，比写博客还有毅力。

今年暑假，通过老师的推荐，成功进入一家制造型企业实习，从事和我专业相关的工作。短短的35天，学习并参与人力资源相关的工作，并且认识了许多同事，具体的情况在文章《[[what-did-i-learn-after-35-days-of-internship|35 天实习之后，我学到了什么？]]》中有介绍，我就不再细说。

通过这次实习，我越发觉得大学生毕业之前参与企业实习是有多么地重要。尤其是文科类专业的同学，在课堂上学的知识和在企业里需要用到的知识有很大的区别，能力要求也有所不同。

最后是关于下半年的秋招，不断地投简历、面试，从这个城市前往另一个城市，好在天道酬勤，自己的努力得到了回报。元旦过后便准备去已签约的公司进行上半年的实习工作。

友情/社交

前两天看到一个段子：

再澄清一次，earth是给你们e人活的，我们i人生活的世界叫做internet，谢谢。

我是i人，ISFJ，确实和我的性格挺符合，较为内向，如果是和不熟的人聊天，三两句就能把天聊死。别看我在 Twitter 和群里如此活跃，但也仅活跃于 Internet。

现实生活中新交到的朋友来自暑假实习，公司的同事。他们大多是90后，也有少数80后，除了该叫经理的叫经理，其他人我都跟着一起叫哥或姐。另外，在暑假实习期间，成功和博友面基，从2018年认识到现在，第一回见面，第一次面基，但也和我上面说的那样，见面之后显得十分拘束，具体内容可以看文章《[[first-meeting-with-blogger-friends|与博友的第一次见面]]》。

互联网上的新朋友更多，大部分通过博客或 Twitter 认识。比如韩宇、Demochen、槿呈、荔枝、Raye、阿甘、小饿、小孙同学、元否、评论尸、枕霞旧梦等等，还有好多好多，我建的中文博客圈微信群已经有132人，比去年增加了不少。我在文章《[[5th-year-of-blogging|写博客的第5年]]》中说写博客给我带来的最大的收获，其中就有“认识了一群有相同兴趣爱好的人”，现在回过头去看这一年，确实如此，又认识了不少有相同兴趣爱好的人。

但是在我的微信好友中也有人离世，曾经邀请过左耳朵耗子加入微信群一起聊天，我还记得当时群里的[[nonsense-collection-7|热闹场面]]，他也特地发了一条推文表达自己的喜悦……

个人生活/家庭

读大学之后，和父母相处的时间越来越少，只有在寒暑假或者假期比较长的节日会在家里度过。因为暑假去企业实习，在家里也只待了十多天，在企业和学校之间来回跑。

双十一给我爸换了一台手机，事先没有和他说，不然肯定会让我退款别买。我就先斩后奏，自己收到手机之后帮他关掉了系统里的广告和推荐，又买了一个手机壳，一起寄回家。等到前一天晚上才打电话给家里说了这个事情。

至于个人生活，和去年一样，比前年要好。4月27日，是和女朋友在一起一周年的日子。我们一起过生日、周年纪念日、七夕节，一起去南昌喝瓦罐汤、登滕王阁、逛万寿宫，一起去萍乡吃炒粉、逛萍乡博物馆、南正街和孔庙……

今年她养了一只银渐层，小小的，特别可爱，因为前段时间身上长猫藓，眼睛也得了结膜炎，便一起去景德镇，在宠物医院打了疫苗，拿了药。以前没养过小动物，现在亲自体会感受到小动物给人类带来的美好感觉。

一切都好，希望来年更好。

学习/知识管理

今年读完的书很少，总共10本。

按照阅读时间顺序从早到晚分别是：《奇风岁月》《可能性的艺术》《狂飙》《愤怒的葡萄》《闲话中国人》《容忍与自由》《刀锋》《番茄工作法》《认知觉醒》《笔记的方法》。

说来惭愧，今年确实对学习和知识管理有所怠慢，除了在学校课堂上学到的知识，以及空闲时间看完的10本书，这个月还在B站上看了几集关于前端的学习视频，计划学习一点关于前端的基础知识，方便我对博客主题进行修改。

如果真要说知识管理，那我今年的重心可能只在管理，而不在知识。包括折腾各种笔记软件、学习各种笔记方法，但实际上记的笔记不多，帮助自己思考的内容也很少，我觉得这是我在未来需要改变的方面。

另外，今年对我影响最大的两本书是《认知觉醒》和《愤怒的葡萄》，前者带给我的感觉是醍醐灌顶，后者带给我的感觉是寒冷、愤怒、悲哀。

旅游/文化

今年2月份，第一次和女朋友去南昌，在那过了21岁生日，登上了滕王阁，逛了万寿宫和珠宝街，吃到了传说中的老三样，以及江西名菜蟹脚捞粉；6月份，和女朋友去南昌看龙舟比赛。

在文章《[[impression-of-nanchang|南昌印象]]》中提到过，南昌给我的总体印象，可以用这几个词概括：人多、热闹、地铁、辣。

另外，作为一个萍乡人，今年国庆假期我和女朋友第一次去萍乡博物馆，第一次听说萍乡还有一条历史文化街区——南正街。在文章《[[light-of-zhaoping-pingxiang-museum|昭萍之光：萍乡博物馆]]》中对博物馆有详细的介绍。

原本想去周边城市逛逛，比如武汉、景德镇，还想坐十多个小时的卧铺，直接北上，去一趟北京，也想南下广东深圳，找群里的朋友面基。但钱包扁扁，也忙着找工作，便耽搁了。

兴趣/创造

似乎兴趣还是老样子，博客、电子产品、阅读。

对于博客，今年换了两次域名。第一次换域名没有激起我写博客的兴趣，因此更新较少，内容不多；第二次换域名，在《Hello，印记！》中提到感谢韩宇，帮我花较低的钱成功注册了十年非常喜欢的域名，重新燃起我对博客的热情和兴趣。

在老杨修改的 Twenty Twelve 主题基础上我再次进行了修改，添加了一点属于我的风格，命名为 2012-huhexian，并将其在 GitHub 平台开源，但仍然还有细节部分不太满意，这也是我想学习前端的原因。

同时，受 Pseudoyu 博客的影响，我也开始写周报，记录过去一周的见闻，加以自己的思考，以及分享发现的有趣事物，目前写到了第7期。也正因为周报，我重新使用 flomo，细心观察生活，随时记录令我有所感悟的事情。

Twitter 和 Telegram 频道应该也算是我的兴趣之一。前者成功获得10K关注，后者也已突破9K订阅，并且通过广告变现尝到了甜头，纯粹是无心插柳柳成荫。

最后还想分享的一个方面是关于 ChatGPT。2022年12月4日注册了 ChatGPT，那个时候还有疫情，在学校需要做核酸、戴口罩，图书馆里天天有人咳嗽。从那之后，各种 LLM 和对应的产品如雨后春笋般出现，到目前为止我使用过 ChatGPT、Bing Chat、Claude、Bard、文心一言、豆包、Perplexity、Pi.AI等工具，最常使用的莫过于搭配沉浸式翻译插件帮助我阅读英文内容，以及让 AI 帮忙润色文本、生成大纲等，也体验过 Bing 集成的 Dall-E-3 模型，画图非常有趣。

情绪/精神状况

今年的整体情况，我认为是有起伏，但也有上升，总体来说是按照好的方向发展。

不管是对人还是对事，我的态度都一样，prepare for the worst, hope for the best.

偶尔会因为各种繁杂的事情袭来，让自己感到焦虑和紧张，因为找工作难度大，对自己产生过怀疑，带来巨大的压力……后面通过自己的解压方式一点点化解。

今年有一个习惯没有坚持，写日记。我将它作为一种解压的方式，把当天发生的事情用笔写下来，一边回忆一边思考，烦恼和压力不知不觉就会从脑海中转移到日记本上。希望明年重新拾起。

财务状况

我一惯的消费习惯是节俭，不管当前手头状况如何。点外卖会用尽一切优惠券，网购会凑满减，下馆子会去美团买团购券。

消费观念也和以前一样，如无必要，勿增实体。买一件商品之前，会思考自己是否需要它，是否有更好的替代品，是否是否急需。

还没有正式工作，对财务状况其实没有太多可说的，但因为有兼职，生活费不用找家里要。

最后三项

最后三项是关于我最骄傲的成就、面对过最大的挑战和明年的目标。

最骄傲的成就

我并没有什么骄傲的成就。如果非要说的话，一方面今年通过兼职、副业赚的钱有小两万，当然存下来没有这么多，另一方面是博客收到了好几个朋友的赞美和欣赏，喜欢我博客的风格、文字，博客访问量也再创新高，让我由衷地感到开心和激励。

在就业困难的大环境下，通过秋招找到一份专业对口的工作，这应该也算是一份骄傲的成就。

最大的挑战

暑假35天的实习，第一次进入职场，第一次进行短暂的身份变化，第一次处理和专业相关的工作，如何快速融入工作环境，是我今年最大的挑战。

当然，生活处处是挑战。

明年的目标和愿望

关于目标和愿望，就不公开了，省得明年打脸。

但会私下记录，明年这个时候再在博客上公布目标达成情况。

以上便是我的2023年度回顾，看起来是如此的普通、平凡，但这不正是我们的生活吗？
